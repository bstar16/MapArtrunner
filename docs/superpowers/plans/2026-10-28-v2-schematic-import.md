## Decisions shared by all slices

`public static BuildPlan SchematicPlanImporter.importPlan(Path path) throws IOException` performs no global/run mutation. Normalize the absolute source path for diagnostics only. I/O/gzip failures use `IOException`; malformed/unsupported content uses contextual `IllegalArgumentException` naming path and field/palette/block index. Preserve expected causes, translate expected native `NbtException`/parser validation errors at this boundary, and do not catch `Error` or blanket-catch unrelated runtime defects.

Accept case-insensitive `.schem`/`.schem.nbt`/`.nbt`; suffix does not select schema. Read gzip NBT through `NbtIo.readCompressed(path, NbtSizeTracker.forLevel())`, retaining its **104857600 tracked-byte** and native depth limits. Accept one optional compound `Schematic` wrapper. Recognize root Sponge `Width/Height/Length/Palette/BlockData` (byte varints **and int array**) and structure `size/palette/blocks`. Do not impose a version whitelist on these recognized shapes. Reject raw NBT, `.schematic`, `.litematic`, numeric legacy Blocks/Data, nested Sponge-v3 Blocks, ambiguous dual schemas and alternate structure palettes explicitly.

Read actual tag types before numeric access: Sponge dimensions may be SHORT or INT, structure sizes/positions/state and palette indices must be INT. Axes must be positive; calculate volume with checked multiplication before allocation/iteration. Dense data must decode exactly volume cells; check bounded input counts before any volume-sized allocation. Sparse structure parsing stays proportional to supplied records, never the declared volume. Palette IDs must be unique/nonnegative; every reference must exist. Varints allow at most five bytes, the fifth payload must fit a nonnegative int, and truncated/overflow/negative/trailing data are errors. Reject duplicate structure positions (including air records), wrong list lengths/types and out-of-bounds positions before dropping air. Sparse absent structure cells mean air.

Parse Sponge states with `BlockArgumentParser.block(Registries.BLOCK, StringReader, false).blockState()` and require exhausted input. Validate structure `Name` and string `Properties` against the same native state rules; omit properties only by accepting their native defaults. Reuse full-state `WorldEvidenceReader.blockSpec(BlockState)` after making that existing stateless converter public. Unknown identifiers/properties/values fail, including unused invalid palette entries. Ordinary property-bearing states remain supported; reject non-air states whose native `asItem()` is `Items.AIR` rather than inventing a material. Do not claim that import proves every specialized block's physical placement route.

All native `state.isAir()` variants mean no required placement; record this clarification from v1's ordinary-air-only behavior. Validate full input before returning an empty plan. Accept positive source height with air padding and one occupied Y; retain original dimensions/coordinates and reject more than one required Y. Retain the reference treatment of offsets (ignored; origin is applied later), with direct tests. For Sponge inspect `Entities`, `BlockEntities` and legacy `TileEntities`; for structure inspect root `entities` and each block record's `nbt`, including air records. Reject nonempty entity/block-entity payloads and wrong types; allow absent or empty correctly typed lists/compounds and benign producer metadata. Reject alternate structure `palettes` and unsupported legacy/nested-v3 construction schemas explicitly. A chest without block-entity payload is not rejected merely because its block can have an entity.

Order non-air targets by Y, occupied Z rows ascending, and alternating X ascending/descending, resetting occupied-row parity for each Y; empty rows do not toggle parity. Assign dense IDs as final list indices. This is import normalization, not a second lane/traversal policy. Fingerprint with SHA-256 over an unambiguous versioned length-delimited encoding of original dimensions, ordered target IDs/coordinates, block IDs, and properties sorted by name. Exclude filename, compression bytes/timestamps, producer metadata, palette numbering and structure list order. Return existing `BuildPlan`; materials and relative chunk `(x >> 4,z >> 4)` groups remain derivable, not duplicated as new model state.
